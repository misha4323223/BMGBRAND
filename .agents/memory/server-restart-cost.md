---
name: Server restart cost
description: Перезапуск сервера стоит ~3 минуты — пользователь явно против лишних рестартов
---

Перезапуск workflow "Start application" занимает около 3 минут:
- YDB Driver init + IAM auth
- Прогрев кэша ~1181 товаров
- Загрузка ~54 000 городов CDEK

**Why:** Пользователь явно попросил не перезапускать сервер без необходимости.

**How to apply:**
- Изменения в `server/` требуют рестарта — всегда предупреждать пользователя ПЕРЕД применением и спрашивать согласие
- Изменения в `client/` применяются через HMR мгновенно — рестарт не нужен
- Если правка затрагивает и server/ и client/ — сначала применить всё, потом один раз спросить про рестарт

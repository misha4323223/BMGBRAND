# Партнёрская программа BMGBRAND — Полное руководство для руководителей

---

## 1. Общая схема работы

Партнёрская программа позволяет физическим лицам и компаниям зарабатывать комиссию, привлекая покупателей на сайт Booomerangs. Есть два типа участников:

- **Обычный партнёр** — продвигает весь ассортимент через личную реферальную ссылку
- **Артист** — автор коллаборации с брендом, получает комиссию за продажи своих товаров напрямую (без реферальной ссылки)

---

## 2. Регистрация партнёра

### Путь на сайте
`booomerangs.ru/partner/register`

### Шаг 1 — Выбор типа юридического лица
Партнёр выбирает один из трёх статусов:
- **Самозанятый** — физическое лицо, плательщик НПД
- **ИП** — индивидуальный предприниматель
- **ООО** — юридическое лицо

### Шаг 2 — Заполнение данных
В зависимости от типа заполняются разные поля:

| Поле | Самозанятый | ИП | ООО |
|---|---|---|---|
| Email / Пароль | ✅ | ✅ | ✅ |
| ФИО | ✅ | ✅ | — |
| ИНН | ✅ | ✅ | ✅ |
| Телефон | ✅ | ✅ | ✅ |
| Название магазина (slug) | ✅ | ✅ | ✅ |
| Название компании / ОГРН | — | ✅ | ✅ |
| Банковские реквизиты | ✅ | ✅ | ✅ |

### Шаг 3 — Подписание документов
Партнёр читает и подписывает Простой Электронной Подписью (63-ФЗ):
- **Оферту партнёрской программы** (текущая версия v2.3.1)
- **Политику конфиденциальности**

Система фиксирует: IP-адрес, геолокацию (страна, регион, город через ip-api.com), дату и время, хэш документа.

После регистрации аккаунт уходит на **ручную модерацию** администратором.

## 3. Личный кабинет партнёра

### Вход
`booomerangs.ru/partner/login`
- Email + пароль (с возможностью показать/скрыть пароль)
- Ссылка «Забыли пароль?»

---

### Вкладка «Обзор»

Главная панель с ключевыми показателями:

| Метрика | Что означает |
|---|---|
| Клики по ссылке | Сколько раз перешли по реферальной ссылке |
| Заказов | Количество оплаченных заказов от рефералов |
| Оборот | Сумма всех заказов от рефералов |
| Ожидают оплаты | Заказы созданы, но ещё не оплачены — комиссия не начислена |
| На удержании (холд) | Оплачено, но 14 дней ещё не прошло (период возврата) |
| Доступно к выплате | Прошли холд + подтверждены администратором — можно запросить выплату |
| Выплачено | Всего получено за всё время |

---

### Вкладка «Моя ссылка»

- Персональная реферальная ссылка вида `booomerangs.ru/r/slug-партнёра`
- Кнопка «Скопировать» и «Открыть»
- **QR-код** — скачать PNG для использования в офлайн-материалах
- **Промокод** — партнёр может создать персональный промокод (4–16 символов), указав скидку для покупателя от 5% до 15%. Покупки по промокоду также засчитываются партнёру даже без перехода по ссылке

---

### Вкладка «Мои товары»

- Партнёр выбирает товары из каталога, которые будут отображаться на его публичной странице (`booomerangs.ru/r/slug`)
- На каждый товар генерируется прямая реферальная ссылка
- Выбранные товары отображаются в виджете

---

### Вкладка «Виджет»

- Готовый код для встраивания витрины товаров на внешний сайт
- Показывает выбранные партнёром товары с ценами и кнопкой покупки

---

### Вкладка «Заказы и комиссии»

Таблица всех заказов с рефералами:

| Колонка | Описание |
|---|---|
| Номер заказа | Кликабелен — открывается в новой вкладке |
| Дата | Когда оформлен |
| Сумма заказа | Полная сумма покупки |
| Комиссия % | Ставка, по которой начислено |
| Сумма комиссии | Итоговое начисление |
| Статус | Ожидает / На удержании / Подтверждена / Выплачена / Отменена |

Строку можно развернуть — отображаются конкретные товары в заказе.

---

### Вкладка «Выплаты»

**Баланс:**
- Сколько «на удержании» (ещё не подтверждено)
- Сколько «доступно к выплате»

**Запрос выплаты:**
- Кнопка активна при любой сумме > 0 ₽ (минимума нет)
- После нажатия статус меняется — уходит на обработку администратору

**История выплат** — таблица со статусом каждой выплаты и загруженными документами.

**Загрузка документов (зависит от типа):**

| Тип партнёра | Что загружает |
|---|---|
| Самозанятый | 1. Счёт → 2. Чек НПД после получения |
| ИП / ООО | 1. Счёт → 2. Подписанный Акт оказанных услуг |

---

### Вкладка «Настройки»

- Изменить название магазина (витрины)
- Изменить контактное лицо и телефон
- Email и slug — только для чтения (меняет администратор)
- Показывается общая сумма заработка за всё время

## 4. Кабинет артиста (дополнительная вкладка)

Если партнёр помечен как **артист** — в кабинете появляется дополнительный блок «Артист» поверх обычного «Обзора».

### Показатели артиста

| Метрика | Описание |
|---|---|
| Оборот по моим товарам | Сумма продаж именно артистских товаров |
| Заказов | Количество заказов с артистскими товарами |
| Продано единиц | Количество штук товаров |
| Начислено в этом месяце | Комиссия за текущий месяц по ставке артиста |
| Начислено всего | Накопленная комиссия за всё время |

### Аналитика

- **График по месяцам** — оборот по месяцам в виде таблицы
- **Топ товаров** — рейтинг своих товаров по выручке и количеству продаж
- **Каталог своих товаров** — плитка с карточками всех товаров, связанных с артистом

### Особенность логики комиссий артиста

- Комиссия артисту начисляется за **каждую продажу его товара** вне зависимости от того, был ли реферал
- Если артист одновременно является реферером заказа (покупатель перешёл по его ссылке), то начисляется только **реферальная комиссия** на весь заказ — двойного начисления нет
- Ставка артиста (`artistRate`) устанавливается администратором индивидуально и не зависит от прогрессивной шкалы

## 5. Администрирование партнёрской программы

Раздел в админке: **«Партнёры»**

---

### 5.1 Список партнёров

Фильтры по статусу:
- **Ожидают одобрения** — новые заявки
- **Одобренные** — активные партнёры
- **Заблокированные** — временно или постоянно
- **Отклонённые** — не прошли модерацию

По каждому партнёру отображается:
- Имя, email, тип (самозанятый / ИП / ООО), артист или нет
- Клики, заказы, общий оборот
- Текущий статус

---

### 5.2 Действия с партнёром

**Изменение статуса:**
- `Одобрить` — партнёр получает доступ в кабинет
- `Заблокировать` — вход запрещён, новые комиссии не начисляются
- `Отклонить` — отказ с возможностью написать причину

**Ставка комиссии:**
- Установить **индивидуальный процент** (переопределяет прогрессивную шкалу)
- Если не задан — работает прогрессивная шкала (15% → 20% → 25%)

**Управление артистом:**
- Включить/выключить флаг «Артист»
- Установить индивидуальную **ставку артиста** (обычно 20–25%)

**Юридические документы:**
- Просмотреть все подписанные документы с IP, геолокацией и хэшем
- Скачать PDF с полным пакетом подписанных соглашений

---

### 5.3 Управление комиссиями

Раздел: **«Комиссии»**

Фильтры: по партнёру, по статусу (ожидает / на удержании / подтверждена / выплачена / отменена)

**Статусы комиссии и переходы:**

```
Заказ создан → [pending] «Ожидают оплаты»
      ↓ оплата прошла (вебхук)
[on_hold] «На удержании» (14 дней)
      ↓ администратор нажимает «Подтвердить»
[confirmed] «Подтверждена» → доступна к выплате
      ↓ выплата произведена
[paid] «Выплачена»

В любой момент: [cancelled] «Отменена» (возврат заказа)
```

**Действия администратора:**
- **Подтвердить** — переводит комиссии в статус «подтверждена». Можно нажать только после истечения 14-дневного холда (или с флагом «форсировать»)
- **Отменить** — при возврате заказа. Комиссия аннулируется
- **Форсировать** — подтвердить досрочно (до истечения холда) — только для администратора

---

### 5.4 Управление выплатами

Раздел: **«Выплаты»**

**Полный цикл выплаты (пошагово):**

**Шаг 1.** Партнёр нажимает «Запросить выплату» в своём кабинете
→ В списке выплат появляется строка со статусом **«Запрошена»**

**Шаг 2.** Администратор открывает запрос, выбирает подтверждённые комиссии партнёра и нажимает **«Создать выплату»**
→ Партнёру приходит уведомление — нужно загрузить счёт

**Шаг 3.** Партнёр загружает счёт (для самозанятых — из приложения «Мой налог», для ИП/ООО — официальный счёт)
→ Статус: **«Счёт загружен»**

**Шаг 4.** Администратор скачивает счёт, производит оплату (СБП / карта / расчётный счёт) и нажимает **«Отметить как оплачено»**
→ Статус меняется:
- Самозанятый → **«Ждём чек НПД»**
- ИП / ООО → **«Ждём подписанный акт»**

**Шаг 5.** Партнёр загружает закрывающий документ:
- Самозанятый — чек из «Мой налог»
- ИП / ООО — подписанный Акт оказанных услуг

**Шаг 6.** Администратор проверяет документ и нажимает **«Завершить выплату»**
→ Статус: **«Завершена»** ✅

**Отклонение выплаты:**
- Администратор может отклонить на любом этапе до оплаты
- Нужно указать причину — партнёр увидит её в кабинете
- Подтверждённые комиссии возвращаются в статус «подтверждена» и снова доступны для следующего запроса

---

### 5.5 Глобальные настройки программы

- **Базовая ставка комиссии** — процент по умолчанию для новых партнёров
- **Период холда** — количество дней до подтверждения (по умолчанию 14)

---

### 5.6 Управление юридическими документами

- Просмотр всех версий оферты и политики конфиденциальности
- Загрузка новой версии документа — становится активной для всех новых регистраций
- Старые версии хранятся бессрочно (для юридической чистоты уже подписанных соглашений)

---

## 6. Прогрессивная шкала комиссий

Действует для обычных партнёров **без индивидуальной ставки**:

| Оборот за месяц | Ставка комиссии |
|---|---|
| До 10 000 ₽ | 15% |
| 10 000 — 20 000 ₽ | 20% |
| Свыше 20 000 ₽ | 25% |

> **Важно:** для артистов прогрессивная шкала **не применяется** — у них фиксированная ставка, установленная администратором.

---

## 7. Атрибуция заказов (как понять, от кого заказ)

Заказ засчитывается партнёру если **выполнено хотя бы одно** из условий:

1. Покупатель перешёл по реферальной ссылке партнёра в течение **30 дней** до покупки
2. Покупатель ввёл промокод партнёра при оформлении заказа

При конфликте (и ссылка, и промокод) — приоритет у **промокода**.

## 10. Быстрая шпаргалка для менеджера

| Задача | Где делать |
|---|---|
| Одобрить нового партнёра | Админка → Партнёры → Ожидают одобрения |
| Установить ставку партнёру | Админка → Партнёры → карточка → «Ставка комиссии» |
| Сделать партнёра артистом | Админка → Партнёры → карточка → «Артист» → вкл. + ставка |
| Подтвердить комиссии | Админка → Комиссии → выбрать → «Подтвердить» |
| Отменить комиссию (возврат) | Админка → Комиссии → найти → «Отменить» |
| Создать выплату | Админка → Выплаты → «Создать» → выбрать комиссии |
| Отметить выплату оплаченной | Админка → Выплаты → нужная → «Отметить оплаченной» |
| Завершить выплату | Админка → Выплаты → нужная → проверить документ → «Завершить» |
| Скачать подписанные документы | Админка → Партнёры → карточка → «PDF документов» |
| Изменить период холда | Админка → Настройки партнёрской программы |

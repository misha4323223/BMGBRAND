# Интернет-магазин BOOOMERANGS — Описание проекта

## Что это

Полнофункциональный интернет-магазин одежды бренда BOOOMERANGS. Современная платформа для онлайн-продаж с личным кабинетом покупателя, оптовым модулем, подарочными сертификатами, блогом и панелью управления для администратора.

Сайт размещён в Яндекс Облаке (Yandex Cloud) — все данные хранятся на российских серверах.

---

## Возможности для покупателей

- **Каталог товаров** с категориями, фильтрацией по размерам и цветам, поиском
- **Карточка товара** с фотографиями, выбором размера, информацией о наличии
- **Корзина** с автоматическим контролем наличия на складе
- **Оформление заказа** в несколько шагов с выбором способа доставки и оплаты
- **Оплата онлайн** через ЮKassa и Т-Банк (Тинькофф)
- **Доставка:** СДЭК (курьер и пункты выдачи) + Яндекс Доставка (пункты выдачи)
- **Личный кабинет:** история заказов, избранное, профиль, отслеживание доставки
- **Подарочные сертификаты:** покупка и использование, отправка по email
- **Система лояльности:** накопительные скидки и промокоды
- **Рекомендации "Собери образ"** — подборка сопутствующих товаров к выбранной вещи

---

## Возможности для оптовых покупателей

- Регистрация оптового аккаунта с подтверждением администратором
- Индивидуальные оптовые цены и скидки
- Сохранение данных доставки для повторных заказов

---

## Панель управления (для администратора)

- **Товары:** создание, редактирование, бейджи (NEW, SALE), скрытие из каталога
- **Заказы:** просмотр, изменение статусов, отслеживание
- **Контент сайта:** редактирование всех страниц (главная, о нас, FAQ, политика конфиденциальности, условия)
- **Блог:** создание и редактирование статей
- **Вакансии:** управление списком открытых позиций
- **Страницы артистов:** настраиваемые блоки (фото, описание, галерея, видео, товары, соцсети)
- **Меню сайта (навбар и футер):** полное редактирование ссылок и содержимого
- **Категории каталога:** создание и управление
- **Промокоды:** создание и настройка скидочных кодов
- **SEO:** настройка заголовков, описаний и ключевых слов для страниц и товаров
- **Аналитика:** дашборд с основными показателями продаж

## Интеграции

| Сервис | Что делает |
|--------|-----------|
| **1С** | Автоматический импорт товаров, цен и остатков (CommerceML). Работает с 1С:УНФ, Управление торговлей, Розница |
| **Bitrix24** | Автоматическая передача заказов и контактов в CRM |
| **Telegram** | Мгновенные уведомления о новых заказах и оптовых заявках |
| **Email** | Подтверждение заказа, отправка сертификатов, уведомления о поступлении товара |

---

## Инфраструктура (Яндекс Облако)

Сайт полностью работает на сервисах Яндекс Облака:

| Что | Сервис |
|-----|--------|
| Хостинг сайта | Serverless Containers |
| База данных | Yandex Database (YDB) |
| Хранение изображений | Object Storage |
| Хранение образов приложения | Container Registry |
| SSL-сертификат (https) | Certificate Manager |
| Маршрутизация запросов | API Gateway |
| Отправка писем | Postbox |
| Доставка | Яндекс Доставка |

Используется серверлесс-модель: оплата только за фактическое использование, без фиксированной платы за сервер.

## Обновление сайта

Для выпуска обновлений:
1. Внести изменения в код
2. Собрать новый образ приложения
3. Загрузить его в Yandex Container Registry
4. Создать новую ревизию в Serverless Containers

Подробная пошаговая инструкция прилагается.
